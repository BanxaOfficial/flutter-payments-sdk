# banxa_payments_flutter_ios

iOS implementation of [`banxa_payments_flutter`](https://pub.dev/packages/banxa_payments_flutter) (PrimerSDK 2.49.0).

**Do not add this package to a partner app.** Depend on `banxa_payments_flutter` `0.1.0` instead. Pub pulls this implementation in automatically.

Minimum iOS is **15.0**. This is a **preview**. See the [repository README](https://github.com/BanxaOfficial/flutter-payments-sdk) for setup and the Swift Package Manager / CocoaPods layout.
