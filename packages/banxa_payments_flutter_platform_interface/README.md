# banxa_payments_flutter_platform_interface

Platform interface for [`banxa_payments_flutter`](https://pub.dev/packages/banxa_payments_flutter).

**Do not add this package to a partner app.** Depend on `banxa_payments_flutter` `0.1.1` instead. This package exists so the iOS and Android implementations can share models, Pigeon messages, and `BanxaPaymentsPlatform`.

This is a **preview**. See the [repository README](https://github.com/BanxaOfficial/flutter-payments-sdk) for setup and floors.
