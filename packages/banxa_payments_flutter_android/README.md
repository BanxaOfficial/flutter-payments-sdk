# banxa_payments_flutter_android

Android implementation of [`banxa_payments_flutter`](https://pub.dev/packages/banxa_payments_flutter).

**Do not add this package to a partner app.** Depend on `banxa_payments_flutter` `0.1.0` instead. Pub pulls this implementation in automatically.

Uses Primer Checkout **`3.0.0-beta.2`** (preview) with minSdk **24**. Do not treat native Android checkout as general availability. See the [repository README](https://github.com/BanxaOfficial/flutter-payments-sdk) for setup and permissions.
